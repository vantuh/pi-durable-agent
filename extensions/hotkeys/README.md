# Hotkeys

`extensions/hotkeys` binds keys to the shell's commands (`session.new`, `folder.pick`, from `@/sdk/commands.ts`) and to stepping through the sidebar's sessions; the defaults and `data/hotkeys.json` are described in its `lib.ts`. Keys bind by physical position (`event.code`), so a binding works on any keyboard layout. A field keeps the keys typed into it; a field inside `[data-shell-keys]` — the composer's textarea carries it — keeps only its typing, and the shell's keys (the session arrows) still reach it. The keymap is also stated to the core ([keys for a shell command](../../docs/extensions.md#keys-for-a-shell-command)): each command's first binding, so a core hint shows what runs it, and the folder's unmount clears them.
